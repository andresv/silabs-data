# silabs-metapac

Peripheral Access Crate (PAC) for Silicon Labs EFR32 and EFM32 chips, with chip metadata.

The crate is generated by [silabs-data](https://github.com/andresv/silabs-data). Do not edit it by hand. Report problems and send changes to silabs-data.

## Usage

Select exactly one chip with a feature. The feature name is the lowercase part number.

```toml
[dependencies]
silabs-metapac = { version = "0.6", features = ["efr32mg24b210f1536im48", "rt"] }
```

```rust,ignore
use silabs_metapac::GPIO;

GPIO.p_dout(silabs_metapac::gpio_port::PORTA).modify(|w| w.set_dout(1 << 5));
```

The registers of one IP version are shared by all chips that have it. Each chip feature selects the peripheral instances, addresses and interrupts of that chip.

## Features

| Feature | Default | Effect |
|---|---|---|
| `pac` | yes | Build the register access API. |
| `metadata` | no | Export `silabs_metapac::metadata::METADATA`: the chip's peripherals, clocks, interrupts, pins, DMA requests and memory. HAL build scripts use it. |
| `rt` | no | Give `cortex-m-rt` the interrupt vector table (`device.x`). |
| `memory-x` | no | Put the chip's `memory.x` (first flash and first RAM region) on the linker search path. Leave it off when the application has its own. |
| `defmt` | no | Implement `defmt::Format` for the register types. |

## Cfgs for dependent crates

The crate has `links = "silabs-metapac"`. So the build script of a direct dependent gets the chip's cfgs in `DEP_SILABS_METAPAC_CFGS` and `DEP_SILABS_METAPAC_CHECK_CFGS`. A HAL forwards them, and needs no chip features of its own:

```rust,ignore
// build.rs of the dependent crate
fn main() {
    println!("cargo:rerun-if-env-changed=DEP_SILABS_METAPAC_CFGS");
    println!("cargo:rerun-if-env-changed=DEP_SILABS_METAPAC_CHECK_CFGS");
    if let Ok(specs) = std::env::var("DEP_SILABS_METAPAC_CHECK_CFGS") {
        for spec in specs.split_ascii_whitespace() {
            println!("cargo:rustc-check-cfg={spec}");
        }
    }
    if let Ok(cfgs) = std::env::var("DEP_SILABS_METAPAC_CFGS") {
        for cfg in cfgs.split_ascii_whitespace() {
            println!("cargo:rustc-cfg={cfg}");
        }
    }
}
```

For a chip with `TIMER0` and an `eusart_s2v2` EUSART, the cfgs include:

- `eusart`, `eusart_s2v2` and `eusart_s2`: the kind, the exact register version, and any version of that series.
- `peri_timer0`, `peri_eusart1`: one per peripheral instance.
- `silabs_series = "2"` and `silabs_series_2_config = "4"`.
